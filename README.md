
    Double-click `index.html` or open it using a local development server like **Live Server** in VS Code.

## 🚀 Deployment

The site is configured for deployment using **Firebase Hosting**.

### Prerequisites
Ensure you have the Firebase CLI installed. If Node/NPM is not installed, you can use the standalone binary:
```bash
# Using Windows Package Manager (winget)
winget install -e --id Google.FirebaseCLI
```

### Deploying Changes
1.  Initialize/login (if deploying for the first time or on a new machine):
    ```bash
    firebase login
    ```
2.  Deploy the static content:
    ```bash
    firebase deploy
    ```
